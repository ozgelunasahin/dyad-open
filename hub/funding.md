### Prototype Fund (DE) — [prototypefund.de](https://www.prototypefund.de/en)
- **What:** BMBF-financed fund for open-source public-interest tech built in Germany. Up to **€95,000 for a team** (€47,500 individual) for 6 months; a second stage up to €63,000 exists. Focus areas: civic tech, software infrastructure, data literacy, IT security.
- **Deadline:** applications for the next class run **1 October – 30 November 2026**.
- **Why dyad fits:** open source, civic framing ("social technology as civic infrastructure" is already dyad's colophon), German team. The governance work (consent process, open documents) reads as exactly their kind of public-interest story.
- **Watch out:** funds individuals/GbR-teams for the *work*, not companies for growth; frame a fundable 6-month scope (e.g. the ATProto privacy-boundary work, or the open-source membership/governance toolkit) rather than "fund dyad."
- **Next step:** pick the scoped project in September; application drafts take ~2 weeks.

## ⚪ Watch list

- **NGI (Next Generation Internet, EU)** — recurring open calls (NGI Zero Commons and successors) fund privacy-preserving, open internet infrastructure, typically €5k–50k per project. dyad's "we can't leak what we never hold" architecture is on-thesis. Check current calls at [ngi.eu](https://www.ngi.eu).
- **Berlin Startup Stipendium** — salary-replacing stipends via Berlin universities/incubators for founders; worth it if a founder needs runway before membership revenue arrives. Rolling per host institution.
- **IBB / GründungsBONUS Berlin** — Berlin grant for young startups (historically up to ~€50k, co-financing). Check current program terms at [ibb.de](https://www.ibb.de).
- **Mozilla / Ford / civic tech foundation funds** — thematic calls come and go; dyad's data-minimal social architecture fits "trustworthy AI / healthy internet" framings when they open.
- **Kulturstiftung / Land Berlin culture funds** — if the zine, /voices films, or the conversation program get framed as cultural practice, small culture grants (often €5k–25k) become available. Lower effort, good for community budget.

## Principles (so this list stays honest)

1. Grants fund the *work*, membership funds the *organization*. Never let a grant redefine the product.
2. Prefer funders whose thesis matches the architecture (privacy, open source, community governance) — those applications write themselves from existing documents.
3. One application in flight at a time; each reuses the same core narrative: offline-first, data-minimal, member-governed, open source.
