# SAB JTF Business Angel Bonus — application working copy

`sab-business-angel-bonus.html` is a self-contained, offline English working copy of the
Sächsische Aufbaubank (SAB) **JTF Business Angel Bonus 2021–2027** online application.

- Open the file in any browser (no server, no build step, no dependencies).
- All 19 sections of the SAB portal, translated to English, with an **EN ⇄ DE** toggle
  (top right) that shows the exact original German wording for each block.
- Form fields save locally in the browser (localStorage) — nothing is uploaded anywhere.

Unofficial aid for understanding only. The binding form is the German original in the SAB portal.
